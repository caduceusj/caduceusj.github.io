The icons shipped with this site are generated from these sources
(`tools/icons-src/`, rebuilt by `npm run build:icons`):

| Used for | Source | Author | License |
|---|---|---|---|
| `silk.png` — colored 16×16 "object" icons (folders, documents, medals…) | [Silk icons](https://famfamfam.com/lab/icons/silk/) | Mark James | [CC BY 2.5](https://creativecommons.org/licenses/by/2.5/) — credit link required (this file and the *About JoãoOS XP* window) |
| inline SVG glyphs (UI controls, GitHub, LinkedIn…) | [pixelarticons](https://github.com/halfmage/pixelarticons) | Gerrit Halfmann | MIT |
| brand marks (Godot, Unity, itch.io, Steam, Python, C++, HTML5, Git, Jira, Oculus…) re-drawn on a 24×24 pixel grid | [Simple Icons](https://simpleicons.org) | Simple Icons contributors | CC0 1.0 — the logos remain trademarks of their owners and only identify the technologies mentioned |
| `skull` icon, favicon / app icons | original pixel art (`tools/icons.config.mjs`, `tools/build-favicon.mjs`) | this project | same as the repository |

The full license texts are vendored next to the sources in `tools/icons-src/*/LICENSE*`.
Fonts: see `assets/fonts/LICENSE-OFL.txt` (Jersey 10, VT323 and Press Start 2P — SIL OFL 1.1).
